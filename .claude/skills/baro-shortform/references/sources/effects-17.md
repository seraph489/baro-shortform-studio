# 영상 효과 17가지 — 바로 숏폼 적용 카탈로그

출처: 원장님 공유 릴스 [@tenfoldmarc "17 video effects claude can create"](https://www.instagram.com/reel/Def9pj5TWtA/) (27초, 2026-10-22 확인). 영상 속 목록과 폰 화면 데모를 장면별로 보고 정리했어요. 효과 이름은 영상 표기 그대로이고, 설명·적용 방법은 우리 병원용으로 새로 썼어요 (외부 화면·문구는 복제하지 않아요).

- **확인:** 👁 = 데모 화면에서 직접 확인 · 📖 = 데모가 작아 효과 이름(일반적인 편집 기법)으로 해석
- **제작:** ✅ 지금 파이프라인으로 가능 · 🔧 템플릿 추가 개발 필요 · 🎥 촬영이 필요(찍을 때 준비)
- **추천 스타일:** 01 바로 모션 · 02 바로 토크 · 03 바로 레이어 · 04 바로 카드 · 05 바로 데일리

## 병원 영상에 쓸 때 주의

- **10 chart grow·08 headline wall:** 숫자·기사 제목은 병원 확정 사실이나 공식 자료만. 지어낸 수치·가짜 기사 제목은 쓰지 않아요.
- **06 phone mockup·03 ui world:** 실제 환자 채팅·예약 화면은 쓰지 않아요. 직접 만든 예시 화면만 써요.
- **12 green screen·04 frame break·14 doodle boil:** 사람 분리 마스크가 필요해서 03과 같은 마스크 시험(머리카락 깜빡임 평균 3/255 이하)을 거쳐요. 손으로 들고 찍은 영상은 피해요.
- **15 vertigo·09 zoom-through cut:** 강한 효과라 영상당 1회까지. 진중한 주제(수술·통증)에는 쓰지 않아요.
- 한 영상에 **새 효과는 1~2개만**. 편마다 하나씩 바꿔 반복 피로를 막아요 (공통 규칙).
- 효과는 모두 [위치 가이드](../placement-guide.md)의 안전구역 안에서. 얼굴·입은 가리지 않아요.
