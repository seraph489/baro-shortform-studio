# 자막·그래픽 위치 가이드

출처: 원장님 공유 릴스 [@ieozoom_studio "자막 위치 하나로 조회수가 갈립니다"](https://www.instagram.com/reel/DeWR-fyyY2F/) (12초, 2026-10-22 확인). 영상 장면을 1초 간격으로 보고 정리했어요. 아래 %는 화면 캡처에서 잰 **대략값(±3%)**이에요. 영상의 문구·디자인은 복제하지 않고 원리만 써요.

## 영상이 말하는 핵심 4가지

| # | 원리 | 영상에서 보여 준 것 |
|---|---|---|
| 1 | **시선 → 자막 → 후킹** 순서로 배치 | 시선이 먼저 가는 곳은 얼굴(눈). 자막은 얼굴 바로 아래, 후킹 제목은 화면 위쪽 |
| 2 | **안전구역(초록)에만** 글자를 넣기 | 화면 가운데 큰 사각형이 초록으로 표시됨 |
| 3 | **위험구역(빨강): 바깥 테두리, 오른쪽, 아래쪽**은 피하기 | 위 띠, 오른쪽 세로 띠, 아래 띠가 빨강. 플랫폼 버튼·캡션·프로필이 덮는 자리 |
| 4 | **배경이 복잡하면 글자에 테두리** | 배경이 어지러운 장면에서 자막 가독성을 테두리로 확보 |
