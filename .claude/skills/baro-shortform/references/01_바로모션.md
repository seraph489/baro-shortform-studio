# 01 · 바로 모션 (기본값)

> 확정 2026-10-20 (test-02 v4b) · YSA 반영 2026-10-21 (v4c)
> 대표 결과물: `output/test-02/test02_age_v4c_sfx_hq.mp4` (19.2초, 효과음 포함 · 2026-10-22 확정)

## 한 줄
원장님 설명을 **컷편집 + 1.1배속**으로 촘촘하게 붙이고, 포인트마다 **펀치인 + 얼굴 앞 핵심어 팝**을 넣고, 판단 기준은 **말하는 순서대로 켜지는 패널**로 보여 줘요.

## 맞는 영상
- 원장님이 정면으로 말하는 15~45초 설명 영상
- "~에 따라 달라요"처럼 판단 기준 2~3개가 나오는 내용
- 통념을 깨는 한 단어가 있는 도입 ("나이?", "그냥?")

## 구성 (24초 원본 → 19.2초 기준)
| 구간 | 요소 | 사양 |
|---|---|---|
| 0~0.1초 | 도입 줌아웃 | 인물만 200% → 100%, 0.10초 |
| 0~3초 | 사선 제목 + 배지 | 가슴 위치, Pretendard Black 118px, skew −12°, 배지 틸 `#0F5C5A`. 첫 대사가 나오면 끊어요 |
| 도입 질문 | 하단 자막 + 약한 흔들림 정착 | M03 약하게 (이동 45px, 기울기 7°, 0.2초) |
| 결론 포인트 | **펀치인 + 핵심어 팝** | 인물만 100% → 125%, 0.12초. 핵심어("나이?")는 310px 흰 글자 + 코랄 물음표, **얼굴 앞 레이어**, 머리 위쪽에서 0→125→96→100% 팝, 약 1.1초 |
| 결론 문장 | 큰 자막 즉시 교체 | M05, 104px. 핵심어는 코랄, 나머지는 작게 섞어요 |
| 판단 기준 | **기준 패널 (M08)** | 화면 40% 어둡게 + 아이보리 패널(폭 702px, y 1150~1530). ①→②→③이 **말하는 순간에 켜지고**, 지금 말하는 항목만 틸 배경 + 팝. 문장이 끝나면 패널도 사라져요 |
| 설명 | 자막 교체 | 자간 수렴 진입(M04) 또는 즉시 교체 |
| 마무리 | 3단 행동 유도 (M09) | 작은 라벨 → 큰 키워드 팝 → 타자기 꼬리 문구 |
| 구도 | 넓은 컷 ↔ 115% 크롭 | 2~4초 간격, 얼굴 중심(540, 800) 기준 |

## 옵션 (2026-10-22 정리)
- **팔로우 카드: 기본 켬** — 끝 2.5초 전, "안양연세바로치과 / 교정 궁금증, 매주 답해 드려요"
- **핵심어 디자인:** `pop`(기본, 위 설명) / `hand`(손글씨로 써짐) / `behind`(사람 뒤, 삼각대 촬영본만). 자세히는 [options.md](options.md)

## 오디오
- 무음 구간으로 잡음을 학습해 제거해요 (`afftdn` nr 14)
- 문장 사이 0.25초를 넘는 무음만 줄여요 (끝음 0.10초, 첫소리 0.08초 보존)
- 컷마다 10ms 페이드, 1.1배속(음높이 유지), 2패스 loudnorm −14 LUFS / TP −1.5
