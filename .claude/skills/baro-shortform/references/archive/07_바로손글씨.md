## plan.json 예 (ep03 시험본)
```json
{
 "style": "07",
 "title": {"badge": "안양연세바로치과 교정 Q&A", "lines": ["우리 아이 교정", "**언제** 시작할까?"], "start": 0, "end": 1.4},
 "subs": [ … 01과 같음 … ],
 "hand": [
  {"text": "6~7세", "start": 9.34, "end": 11.9, "x": 540, "y": 330, "size": 230, "color": "white", "rotate": -4, "per": 0.16},
  {"text": "교정과에 한 번!", "start": 11.96, "end": 14.2, "x": 540, "y": 1425, "size": 110, "color": "white", "rotate": -3, "per": 0.08}
 ],
 "panel": { … }, "cta": { … },
 "follow": {"text": "안양연세바로치과", "sub": "교정 궁금증, 매주 답해 드려요", "start": 19.6},
 "sfx": [{"t": 9.34, "file": "18_타이핑.wav", "gain_db": -16, "why": "손글씨 써짐"}]
}
```

| 필드 | 뜻 |
|---|---|
| `hand[].text` | 쓸 문구. `//`로 줄바꿈 |
| `hand[].x`, `y` | 글자 덩어리의 **가운데** 좌표 (1080×1920). 머리 위는 y 300~400, 자막 아래는 y 1400~1450 |
| `hand[].size` | 글자 크기 px. 핵심어 200~240, 문장 90~120 |
| `hand[].color` | `white`(어두운·복잡한 배경) / `navy`(밝은 단색 벽) / `coral` |
| `hand[].per` | 글자 하나 쓰는 시간(초). 짧은 단어 0.14~0.18, 문장 0.07~0.1 |
| `hand[].rotate` | 살짝 기울기 (기본 −3°) |
| `subs_layout` | `"top"`이면 자막을 머리 위(y 250) 작은 한 줄로 |

## 꼭 지킬 것
- 손글씨는 위 띠(y 230) 아래, 아래 끝(y 1500) 위, 가로 x 140~940 안에
- 배경 색을 보고 글자색을 고른다: 갈색 선반·진열장 앞은 `white`, 흰 벽 앞은 `navy`
- 머리 위에 손글씨를 쓰는 구간엔 자막을 가슴 위치로 (둘 다 위에 두면 겹침)
- 손글씨는 영상당 2~3개까지. 다 써진 뒤 최소 1.2초는 보이게 (`end - start ≥ 글자수×per + 1.2`)
- 효과음은 `18_타이핑`을 작게(−16dB 안팎). 사각사각 느낌
