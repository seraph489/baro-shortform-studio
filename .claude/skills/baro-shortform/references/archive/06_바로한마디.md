## 한 줄
처음 1~1.5초 **배지 + 제목**(01과 같음)으로 주제를 보여 주고, 말하는 동안 **한두 단어씩 큰 자막**이 바뀌어요. 설명하는 대상이 나오면 자막 아래에 **사진 인셋**이 잠깐 뜨고, 끝에 **팔로우 카드**로 마무리해요. 모션그래픽은 적고 말의 리듬이 주인공이에요.

## 레퍼런스에서 본 특징
| 요소 | 레퍼런스 | 우리 적용 |
|---|---|---|
| 후킹 헤드라인 | 첫 ~4초, 위쪽 3줄, 대문자, 단어마다 다른 색(회색 취소선 · 초록 · 파랑) | **쓰지 않음** (2026-10-22 원장님: 별로) → 대신 01과 같은 **배지 + 제목**으로 주제를 먼저 보여 줌. `headline` 옵션은 템플릿에 남아 있지만 기본으로 쓰지 않아요 |
| 자막 | 한두 단어씩 아주 빠르게 교체, 흰 굵은 글자, 가슴 높이 | `word_captions`: 컷 받아쓰기로 자동 생성 (공백 빼고 8자·2단어 이하), 84px, 강조 단어 코랄 |
| 사진 인셋 | 말하는 대상의 임상 사진이 둥근 카드로 자막 아래에 | `insets`: **환자 사진 금지** → 모형 사진, 직접 만든 도식, 장비 사진만 (y 1300~1500) |
| 장면 | 복도 걷기 → 진료 체어 앞 등 장소를 바꿔 점프 컷, 손에 들고 촬영 | 여러 장소에서 찍은 촬영본을 이어 붙일 때 잘 맞아요. 한 장소면 줌 없이 그대로 |
| 마무리 | 끝에 계정 팔로우 카드 | `follow`: 병원 계정 이름 + **소개 한 줄 "교정 궁금증, 매주 답해 드려요"** + "팔로우" (원장님: 좋음, 2026-10-22 소개 한 줄 추가) |
| 길이 | 50초 넘는 공감형 설명 ("당신 잘못이 아니에요") | 길고 말 많은 설명 영상에 특히 좋아요 |

## 맞는 영상
- 말이 많고 긴 설명 (30초 이상): 01의 패널·팝 없이도 자막 리듬으로 끝까지 보게 해요
- 부모님·환자의 걱정을 풀어 주는 공감형 내용 ("양치 잘했는데 왜 검은 선이…")
- 장소를 옮겨 다니며 찍은 영상, 손에 들고 찍은 영상 (마스크가 필요 없어서)

## plan.json 예 (ep04 시험본)
```json
{
 "style": "06",
 "title": {"badge": "안양연세바로치과 교정 Q&A", "lines": ["성인 교정,", "**지금** 늦었을까?"], "start": 0, "end": 1.5},
 "word_captions": {"highlight": ["나이", "잇몸", "판단합니다"], "from": 1.5},
 "insets": [{"src": "insets/model_crowding.jpg", "start": 8.0, "end": 10.5}],
 "follow": {"text": "안양연세바로치과", "sub": "교정 궁금증, 매주 답해 드려요", "start": 14.2},
 "zoom": [],
 "sfx": [{"t": 14.2, "file": "12_마무리_확인.wav", "gain_db": -10}]
}
```
- `insets[].src`는 작업 폴더 기준 경로. 사진은 직접 찍은 모형·장비·도식만 써요.
- 01 요소(`keyword`, `panel`, `zoom`)도 같이 쓸 수 있어요. 다만 이 스타일은 "덜어 내는" 맛이라 하나 정도만.

## 꼭 지킬 것
- 제목이 끝나는 시각을 `word_captions.from`으로 줘서 제목과 자막이 겹치지 않게 해요
- 한두 단어 자막도 발화 그대로. 애매한 말은 `srt_skip`에 넣어 빼요
- 인셋에 환자 입안·얼굴 사진 금지 (레퍼런스와 가장 다른 점)
- 팔로우 카드의 계정 이름은 실제 병원 계정으로 (지금은 병원 이름으로 넣어 둠)
