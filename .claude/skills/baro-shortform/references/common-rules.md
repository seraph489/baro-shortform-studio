# 모든 스타일 공통 규칙

## 원장님 결정 (2026-10-20 ~ 22)
- 모션그래픽이 기본. 정적인 안은 대안으로만.
- 영상이 화면 전체를 채운다. 원장님 영상 없이 글자만 있는 전체 화면 카드는 쓰지 않는다 (test-02 A안 거절).
- 컷편집 + 1.1배속이 기본. 문장 사이 0.25초 넘는 무음만 줄이고 끝음 0.10초·첫소리 0.08초는 남긴다. "~요" 끝음과 ㅊ·ㅋ·ㅌ·ㅍ 첫소리는 자르지 않는다.
- 음량은 −14 LUFS 수준. 일괄로 키우지 않고 영상마다 재서 맞춘다.
- 자막은 원장님 발화 그대로 (단정 표현도 그대로). 받아쓰기로 확인되지 않는 애매한 말과 말 고침은 자막 없이 넘어간다. 매번 묻지 않는다.
- 효과음 기본 배치는 01 문서. 영상당 3~5개, 목소리보다 작게.

## 금지
- 환자 영상·사진·상담 녹음·식별정보 (이름표·차트·모니터·예약표 포함)
- 외부 레퍼런스의 문구·배지색·음원·장면 순서 복제
- 얼굴·입·손·설명용 모형 가리기
- 원본 영상 수정·이동·삭제 (`report.json`의 `input_unchanged`로 확인)
- 승인 없는 게시. 결과물은 원장님 확인 전까지 내부 검토용

## Reels 규격 (YSA ffmpeg-skill 기준, `pipeline.py check`가 검사)
| 항목 | 기준 |
|---|---|
| 화면 | 1080×1920 (9:16), 30fps, 90초 이하 |
| 영상 | H.264, `yuv420p` TV 범위 (JPEG 프레임에서 오면 풀 범위로 나오니 변환 필수) |
| 오디오 | AAC 48kHz 스테레오, −14 LUFS ±2, 피크 −1 dBFS 이하 |
| 안전영역 | 위 8%(y 154 이하)·아래 20%(y 1536 이상)에 핵심 글자 금지 |

## 위치 (자막 위치 릴스 기준, 자세히는 placement-guide.md)
- 안전구역: 가로 약 10~87%, 세로 약 12~78%. 위 띠·오른쪽 13%·아래 띠는 피한다.
- 시선 → 자막 → 후킹: 얼굴 바로 아래 자막, 후킹 제목은 위쪽(단 y 230 아래).
- 배경이 복잡하면 자막에 테두리.
- **글자 요소끼리 겹치지 않기:** 렌더할 때 모든 프레임에서 자막·제목·핵심어·패널·마무리·말풍선·팔로우 카드·손글씨가 서로 겹치는지 자동 검사한다 (`overlaps_*.json`, 로그 "글자 요소 겹침"). 겹침이 남으면 시각을 옮기거나 문구를 줄여 다시 렌더한다. 팔로우 카드 위 요소는 자동으로 올리고 줄인다.

## 모션·타이밍 (YSA motion-polish)
- 글자 여러 개는 0.04~0.08초 시차. 읽어야 할 글자는 다 들어온 뒤 1.2초 이상 유지.
- 한 화면에서 동시에 움직이는 요소는 2개까지. 펀치인은 인물 레이어에만.
- 편마다 한 가지만 바꿔 반복 피로를 막는다 (제목 위치, 강조 방식, 전환 중 하나).

## 진행 원칙
- 계획(장면표·자막·효과)을 먼저 보여 주고 승인받은 뒤 렌더한다.
- 자막은 컷편집이 끝난 뒤 마지막에 넣는다.
- 결과를 보내기 전에 직접 본다: 장면 시트, 첫·끝 검은 프레임, 자막 겹침, 소리 잘림.
- 출처가 있는 자료(효과음·사진)는 라이선스를 `assets/sfx/README.md` 같은 기록에 남긴다. Mixkit 효과음은 파일 자체 재배포 금지라 내부 보관만.
