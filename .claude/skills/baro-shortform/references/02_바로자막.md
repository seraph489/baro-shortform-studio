## 한 줄
말하는 대로 **한두 단어씩 큰 자막**이 바뀌는 차분한 스타일이에요. 패널·팝·잦은 줌 없이 자막 리듬으로 끝까지 보게 해요. 처음엔 01과 같은 **배지 + 제목**, 끝엔 **팔로우 카드**.

## 맞는 영상
- 말이 많고 긴 설명 (30초 이상), 주의사항·부작용 안내처럼 차분해야 하는 주제
- 걱정을 풀어 주는 공감형 내용
- 판단 기준이 뚜렷하지 않아 01의 기준 패널이 어색한 영상
- 손에 들고 찍었거나 장소를 옮겨 찍은 영상

## 구성
| 요소 | 사양 |
|---|---|
| 컷·오디오 | 01과 같음 (컷편집 + 1.1배속 + 잡음 제거 + −14 LUFS) |
| 제목 | 앞 무음 구간에 배지 + 제목, 첫 대사에서 끊음 |
| 자막 | `word_captions`: 컷 받아쓰기로 **자동 생성**. 공백 빼고 8자·2단어 이하, 84px 흰 굵은 글자 + 테두리, 가슴 높이. `highlight` 단어는 코랄. `from`은 제목이 끝나는 시각 |
| 줌 | 쓰지 않거나 결론에 펀치인 1번 정도 |
| 사진 인셋 | (선택) `insets`: 모형·도식·장비 사진만. **환자 사진 금지** |
| 마무리 | 팔로우 카드 (옵션, 기본 켬) |
