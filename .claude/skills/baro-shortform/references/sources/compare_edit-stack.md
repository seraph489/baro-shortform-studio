# 다른 PD 방식(edit-stack)과 우리 방식 비교

비교 대상: artgourmet.cloud "edit-stack" 가이드 (20년 차 영상 PD, 2026-10 기준, 원장님 공유). 2026-10-22 정리.

## 결론
**큰 흐름은 같고, 우리 쪽이 병원 숏폼에 더 맞게 깊이 들어가 있어요.** 그쪽에서 좋은 점 2가지(다시 말한 문장 처리, SRT 자막 파일)만 가져와 반영했고, 나머지는 우리 것이 같거나 낫거나 병원에 맞지 않아서 그대로 둬요.

## 흐름 비교
| 단계 | 그 PD 방식 | 우리 방식 (baro-shortform) | 판단 |
|---|---|---|---|
| 받아쓰기 | Whisper(faster-whisper, 파이썬) | whisper.cpp large-v3-turbo (Mac 가속) + 단어 신뢰도 + 음성 에너지로 싱크 보정 | 같은 계열. 우리 쪽 유지 |
| 다시 말한 문장 | "틀린 문장은 마지막 테이크만" | (없었음) | **가져옴** → `analyze`가 NG 후보 표시, `cut --drop`으로 빼기 |
| 자르기 | FFmpeg, 긴 쉼 줄이기, 말꼬리 보존 | 무음만 줄이기 + 끝음 0.10초·첫소리 0.08초 보존 + 컷 경계 10ms 페이드 + `--keep` + 재받아쓰기 비교 | 우리 쪽이 더 촘촘. 유지 |
| 속도 | 언급 없음 | 1.1배속 (원장님 결정) | 유지 |
| 소리 | "음량만 −14 LUFS, 보정은 하지 마" | 잡음 제거 + −14 LUFS (KMH 규칙, 원장님 결정) | 다름. 우리는 진료실 에어컨 소음이 있어 잡음 제거 유지. 목소리가 이상하게 들리는 영상이 나오면 그때 끄기 |
| 모션그래픽 | 하이퍼프레임즈 (코드로 짠 그래픽 → 영상) | HTML 템플릿 + Playwright 캡처 + 합성 (같은 원리를 직접 구현) | 같은 방식. 우리 템플릿에 병원 규칙(안전구역·입 가림 금지)이 들어 있어 유지 |
| 시리즈 대량 생산 | 리모션 (같은 틀, 다른 내용) | plan.json만 바꾸면 같은 틀로 다음 편 | 같은 효과. 리모션은 **직원 4명 이상 회사는 유료 라이선스**라 병원엔 불리 → 쓰지 않음 |
| 자막 파일 | SRT, 한 줄 14자 안팎 | (화면 자막만 있었음) | **가져옴** → 렌더할 때 `output/<이름>.srt` 같이 생성 (14자 안팎) |
| 내레이션 | 구글 AI 스튜디오 TTS | 원장님 실제 목소리 | 병원 신뢰에는 실제 목소리가 맞아요. 05 바로 데일리에서 목소리가 필요할 때만 검토 (AI 음성 표시·약관 확인) |
| 검수 | 장면을 한 장으로 모아 확인 | 장면 시트 + Reels 규격 10항목 자동 검사 + 원본 해시 비교 | 우리 쪽이 더 엄격. 유지 |
| 원본·권리 | 원본 백업, 쓸 권리 있는 것만 | 원본 수정 금지(해시로 확인), 효과음 라이선스 기록, 환자 정보 금지 | 같음 + 의료 규칙 추가 |

## 그쪽에 없고 우리에게만 있는 것
- 스타일 01~06 추천과 1차본 비교 → 최종 업로드본 결정
- 효과음 자동 배치·목소리보다 작게 자동 조정
- 위치 가이드(안전구역) 자동 준수, 긴 글자 자동 축소
- 편집 화면(직접 고치고 렌더), 끝 지점 자르기
- 사람 뒤 글자(배경 분리), 의료 표현·환자 정보 규칙

## 반영한 변경 (2026-10-22)
1. `pipeline.py analyze`: 무음으로 나눈 문장끼리 앞부분이 비슷하면 "다시 말한 문장(NG 후보)"로 표시
2. `pipeline.py cut --drop 3.2-7.9`: NG 테이크(원본 시각 구간)를 빼고 마지막 테이크만 남김
3. `pipeline.py encode`: 전체 대사 SRT를 `output/<이름>.srt`로 저장 (한 줄 14자 안팎, 첫 소리에 맞춤, `plan.srt_skip` 단어 제외)
