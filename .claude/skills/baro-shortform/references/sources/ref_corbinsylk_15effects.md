## 영상이 소개하는 효과 15가지 (목록 판독)
| 효과 | 우리 쪽 대응 |
|---|---|
| Cinematic grade | 색 보정. 진료실은 밝은 톤 유지 → 쓰지 않음 |
| Person pop out | 03 바로 레이어(사람 분리)와 같은 기술 |
| Image collage | 효과 17의 13 paper cut과 비슷 |
| Chat drop | 채팅 말풍선이 떨어짐 → 환자 채팅 금지, 직접 만든 예시 질문으로만 |
| Over the shoulder zoom | 어깨 너머 줌. 촬영 필요 |
| Apple UI key cards | UI 카드 (효과 17의 03 ui world) |
| Dynamic checklist | 01 기준 패널 (체크) |
| Match cut | 장면 전환 (촬영 설계 필요) |
| Velocity line graph | 효과 17의 10 chart grow (확정 수치만) |
| Iris effect | 원형으로 열리고 닫히는 전환 |
| Product demo | 장비·제품 소개 화면 |
| Freebie doc | 자료 카드 (예: 상담 전 체크리스트 PDF 안내) |
| Zoom through cut | 효과 17의 09와 같음 |
| Cursor tracker | 화면 녹화 위 커서 따라가기 |
| Pixelated screen close up | 화면 클로즈업 픽셀 질감 |
