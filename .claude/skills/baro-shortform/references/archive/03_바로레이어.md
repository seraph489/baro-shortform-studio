# 03 · 바로 레이어

> 기반: 코드 기반 모션그래픽 레퍼런스(prompt_what 사례의 원리) + rembg 시험
> 대표 결과물: `output/full/ep02_laminate_full_hq.mp4` (12.2초), `output/test-02/test02_age_v3_hq.mp4`

## 한 줄
원장님 **뒤로** 큰 핵심어가 지나가는 모션그래픽이에요. 글자 아래쪽이 머리카락 뒤로 숨어서 입체감이 생겨요.

## 맞는 영상
- 통념을 깨는 한 단어로 시작하는 영상 ("그냥?", "무조건?", "나이?")
- **삼각대 고정** 촬영, 머리 위 여백 350px 이상, 무늬 없는 배경

## 구성
| 항목 | 사양 |
|---|---|
| 레이어 | 인물(줌) → 핵심어 → 인물 컷아웃(마스크도 같은 줌) → 자막 |
| 핵심어 | 250~310px Pretendard Black, 흰 글자 + 그림자, 코랄 강조 1자. 팝 진입, 1.0~1.5초. 영상당 1회 |
| 위치 | 글자 아래쪽 끝이 이마보다 최소 100px 위. 아래쪽 80~150px만 머리 뒤로 숨겨요 |
| 마스크 | rembg `birefnet-portrait` (`tools/.venv-rembg`), 효과 구간 프레임만. CPU에서 프레임당 약 40초 |
| 그 외 | 컷·오디오·자막은 바로 모션과 같아요 |

## 글자 디자인 (`keyword.look`)
| look | 모습 | 쓰기 좋은 때 |
|---|---|---|
| (기본) | 흰 고딕 굵은 글자 + 팝 | 숫자·짧은 핵심어 |
| `glass` | 반투명 유리 글자, 밝은 테두리 (효과 17) | 배경이 밝거나 고급스러운 느낌 |
| `cover` | 명조 제호 + 위쪽 호수 표기, 차분하게 등장 (효과 16) | 시리즈 표지 느낌, 도입 |
- `cover` 제호 폰트는 macOS 기본 AppleMyungjo예요 (렌더하는 Mac에 있어야 해요).
- 글자 아래쪽 끝이 머리카락에 50~100px 걸치고 이마보다 위에 있게 `top`/`size`를 정해요. 위 띠(y 230) 아래에서 시작해요.

## 마스크 시험 (통과해야 사용)
1. 머리카락 영역 프레임 간 마스크 변화 평균 3/255 이하 (시험 결과: 1.47, 1.88)
2. 글자가 이마·눈썹·입에 닿지 않음 (펀치인 후 위치로 확인)
3. 통과하지 못하면 → **바로 모션의 얼굴 앞 핵심어**로 바꿔요

## 참고
- 원장님은 test-02에서 얼굴 **앞** 방식(바로 모션)을 골랐어요. 이 스타일은 머리 위 여백이 넉넉한 촬영본이 있을 때 쓰는 선택지예요.
