## YSA 규칙으로 확정본을 점검해서 고친 것 (v4b → v4c)

| 발견 | 원인 | 조치 | 결과 |
|---|---|---|---|
| 픽셀 형식이 `yuvj420p`(풀 범위) | JPEG 프레임 입력에서 범위가 그대로 넘어옴 | `scale=in_range=full:out_range=tv,format=yuv420p` | `yuv420p`, `color_range=tv` |
| 기준 패널 하단이 y 1630 | Reels 하단 20%(y 1536 아래) 침범 | 패널을 y 1150~1530으로 줄임 (입 아래에서 시작) | 안전영역 안, 입 가림 없음 |
| 컷 경계 페이드 없음 | 컷 지점에서 '틱' 소리가 날 수 있음 | 구간마다 10ms 페이드 인/아웃 | 길이 19.20초 그대로, −14.0 LUFS |

## 가져오지 않은 것
- 사진관 고정 사실·문구·말투 규칙, 갈색·크림·골드 색 토큰
- 일레븐랩스 TTS (원장님 실제 목소리를 쓰니까요)
- 스킬 zip 설치 (프로젝트에 넣지 않았어요. 필요할 때 따로 승인받고 설치해요)
- ffmpeg-skill `check.py`는 실행해 봤지만 격리 모드(`-I`)에서 모듈을 찾지 못해 멈췄어요. 같은 기준(`_platforms.py`의 reels 사양)을 직접 측정해서 확인했어요.
