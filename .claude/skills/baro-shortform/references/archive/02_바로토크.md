## 한 줄
**모든 대사를** 짧은 단위로 자막에 넣고, 핵심어만 코랄색과 큰 크기로 섞어요. 효과는 펀치인과 팝만 쓰는 차분한 스타일이에요.

## 맞는 영상
- 말이 빠르거나 정보가 많아 자막이 꼭 필요한 영상
- 소리 없이 보는 시청자를 고려해야 하는 영상
- 바로 모션이 과하게 느껴지는 주제 (주의사항, 부작용 안내 등)

## 구성
| 항목 | 사양 |
|---|---|
| 컷 | 바로 모션과 같아요 (컷편집 + 1.1배속 + −14 LUFS) |
| 제목 | 앞 무음 구간(보통 1~1.5초)에 배지 + 제목, 첫 대사에서 끊어요. 무음이 없으면 제목 없이 시작해요 |
| 자막 | 모든 대사, 62px Medium/Bold 흰 글자 + 그림자, 가슴 높이(y≈1170). 핵심어는 코랄 `#FFB39F` + 1.32배 + Black |
| 싱크 | 받아쓰기 시각이 아니라 **실제 음성 에너지** 기준으로 맞춰요 |
| 펀치인 | 1.15~1.18배, 결론·행동 유도 대사에서만 |
| 팝 | 포인트 자막에 0 → 125 → 96 → 100% |
| 자료 | 받은 자료(사진·그래프)가 있을 때만, 해당 단어에 등장해서 그 문장 끝에 사라져요. 자막 아래, 안전영역 안 |
| 효과음 | KMH 표 기준 (사진 등장 '뽁', 포인트 '뿅·띵' 등). 음량은 목소리보다 작게, 저음 제거 |

## 꼭 지킬 것
- 문장 끝음("~요")과 첫소리(ㅊ·ㅋ·ㅌ·ㅍ)는 자르지 않아요
- 컷 후 다시 받아써서 원본과 비교해요
- 말 고침("치아 범위, 이동하는 범위")은 자막에서 빼요. 애매한 말은 자막 없이 넘어가요
