# 스타일 추천 가이드

추천은 **스타일 1개 + 옵션**으로 짧게. 비교가 필요하면 2개까지 1차본을 만들어 나란히 보여 준다. 원장님이 고른 것이 최종 업로드본.

## 1. 스타일 고르기
| 촬영본·내용 | 스타일 |
|---|---|
| 원장님 정면 설명, 판단 기준 2~4개가 나옴 ("~에 따라", "A, B, C를 봐요") | **01 바로 모션** (기본, 원장님 확정) |
| 말이 많고 긴 설명(30초+), 주의사항·부작용, 판단 기준이 뚜렷하지 않음, 손에 들고 찍음 | **01 바로 모션** (패널 대신 자막 위주로). 02 바로 자막은 원장님 비선호(2026-10-24) — 요청할 때만 |
| 말하는 사람 없이 진료실·장비·직원 일상 컷 여러 개 | **03 바로 데일리** (설계만, 처음 만들 때 템플릿 추가) |
| 환자가 보이는 구간이 있음 | 그 구간을 잘라 내기 전엔 진행하지 않음 |

## 2. 옵션 고르기 ([options.md](options.md))
| 신호 | 옵션 |
|---|---|
| 통념을 깨는 한 단어 ("나이?", "그냥?", "6~7세") | 핵심어 `pop` (기본) |
| 아이 교정, 상담 권유처럼 따뜻한 주제 | 핵심어 `hand` (손글씨) — 선택. 원장님은 `pop`을 더 좋아함 (2026-10-24) |
| 삼각대 고정 + 머리 위 여백 350px 이상 + 입체감 원함 | 핵심어 `behind` (마스크 필요, 시간 더 걸림) |
| 배경에 진열장·책장이 자막 뒤로 비침 | 자막 테두리 (자동) |
| 원장님이 시청자 질문을 읽으며 시작 ("~이런 질문 많이 받아요") | 시청자 질문 말풍선 `chat` — 이런 영상이면 기본으로 넣기 (2026-10-24) |
| 숫자·비용 이야기 | 효과음 `19_코인_카칭` 추가 |
| 팔로우 카드 | 항상 기본 켬 |

## 2-1. 자료 요청
옵션·효과에 자료가 필요하면 추천과 같이 짧게 요청한다. 없으면 그 효과 없이 만든다.
| 효과 | 요청할 자료 |
|---|---|
| 사진 카드·궤도·벽 액자 | 장치·모형 사진 (얼굴·이름 없이, 환자 사진이면 동의 확인) |
| 차트 | 병원이 확인한 수치와 출처 |
| 폰 목업·UI 카드·커서·픽셀 확대 | 예약·상담 화면 캡처나 화면 녹화 (실제 환자 정보 없이) |
| 자료 표지 카드 | 실제로 나눠 줄 자료 제목 (없는 자료는 만들지 않음) |
| 배경 바꾸기 | 바꿀 배경 사진 (진료실·병원 외관 등) |

## 2-2. 효과 나눠 넣기 (2026-10-24 원장님: 다 넣으면 혼잡, 적당히 나눠서)
**한 영상 = 구간 3개 × 구간마다 대표 효과 1개.** 기본(펀치인·자막·팔로우 카드)은 세지 않는다.

| 구간 | 하는 일 | 고를 효과 (하나만) |
|---|---|---|
| 도입 0~3초 | 질문으로 붙잡기 | 말풍선 `chat` · 원형 열림 `iris` · 궤도 사진 `orbit` · 헤드라인 벽 `headline_wall`(통념 나열 영상) |
| 본문 | 기준·비교 설명 | 기준 패널 `panel` · 사진 카드 `photos`(장치 비교) · UI 카드 `ui_card`(확인 항목) · 차트 `chart`(확정 수치) · 종이 콜라주 `paper_cut`(아이 교정) |
| 마무리 끝 3초 | 상담·팔로우로 이어 주기 | 뒤로 빠지기 `pull_back` · 폰 목업+커서 `phone`+`cursor`(예약 안내) · 자료 카드 `freebie`(실제 자료) |

강조 한 번(선택, 결론 순간): 핵심어 `pop` 또는 액자 탈출 `frame_break` · 손그림 외곽선 `doodle` 중 **하나**.

규칙
- 새 효과(지난 편에 없던 것)는 영상당 1~2개. 나머지는 익숙한 것으로.
- 효과끼리 최소 2초 띄운다. 한 화면에 움직이는 요소는 2개까지.
- 같은 역할 효과는 함께 쓰지 않는다: 패널·사진 카드·UI 카드는 셋 중 하나, 말풍선·궤도·헤드라인 벽도 셋 중 하나.
- 영상 효과(배경 바꾸기·액자 탈출·손그림·뒤로 빠지기)는 영상당 1개, 1~1.5초만.
- 20초 이하 영상은 구간 2개(도입+본문)만, 30초 넘으면 본문에 하나 더 가능.
- 픽셀 확대·커서·벽 액자는 화면 녹화·삼각대 촬영이 있을 때만.

주제별 추천 조합
| 주제 | 도입 | 본문 | 마무리 | 강조 |
|---|---|---|---|---|
| 장치 비교 (투명교정 vs 브라켓) | 말풍선 | 사진 카드 | 뒤로 빠지기 | 핵심어 팝 |
| 판단 기준 (나이·시기·발치) | 말풍선 | 기준 패널 | 팔로우 카드만 | 핵심어 팝 |
| 흔한 오해 풀기 | 헤드라인 벽 | UI 카드 (사실 확인) | 뒤로 빠지기 | 액자 탈출 |
| 아이 교정·습관 | 궤도 사진 | 종이 콜라주 | 팔로우 카드만 | 손그림 외곽선 |
| 기간·비용·통계 | 원형 열림 | 차트 (확정 수치) | 자료 카드 | 핵심어 팝 |
| 예약·상담 안내 | 말풍선 | UI 카드 | 폰 목업 + 커서 | — |

## 3. 반복 피로
최근 2~3편과 똑같은 조합만 연속으로 추천하지 않는다. 같은 스타일이면 옵션 하나를 바꾼다 (예: 핵심어 `pop` → `hand`).

## 4. 추천 출력 형식
```
이 영상: (주제 한 줄, 길이, 촬영 상태)
추천: 01 바로 모션 — 도입 말풍선 / 본문 사진 카드 / 마무리 뒤로 빠지기 / 강조 핵심어 팝
  이유: 판단 기준 2개(꼭 필요한지 · 언제가 효율적인지), 아이 교정이라 부드러운 손글씨가 어울려요
비교안(선택): 01 + 다른 옵션 조합 (예: 패널 ↔ 사진 카드, 팝 ↔ UI 카드)
필요 자료: (있으면 좋아요) 장치 사진 2장 — 투명교정·브라켓, 얼굴 없이
```
